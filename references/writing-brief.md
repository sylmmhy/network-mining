# 单人章节写作说明（可以直接交给助手）

## 背景

Eazo 是一个 AI agent 产品，目的是**帮人从自己的人脉中发现能做的事**。我们在研究：
一个人刚把 LinkedIn 链接给 Eazo 时，Eazo 读完他的公开内容和身边人的动态，能说出什么让他觉得"你真懂我、真有用"，之后又能持续帮他做什么。

你负责写其中一个人。**先懂人，再想能做什么**：先写他是谁、为什么这么做、为什么回谁不回谁，最后才写能为他做什么。
方法细节见同目录的 `method.md`，成品样例见 `example-private.md`（只存本地，没有就跳过）。动笔前把这些文件读完。

## 你会拿到

- `digest.md`：他的帖子（OWN 是原创，REPOST 是转发）、他写的评论、热门帖下别人的留言、互动最多的 5 个人最近的帖子。文件很大，分段读完，不要只读开头。
- `stats.txt`：motive_stats.py 算出来的行为事实（A–J 节）。这是写动机和"回谁不回谁"的主要依据。
- 原始数据目录（posts.json、comments.json、threads.json、partners.json）：需要核对细节时查。
- 编号、今天的日期、输出文件路径。

## 硬性规矩

1. **每条结论都附证据链接。** 链接原样取自 digest.md 或原始数据，不编链接、数字和日期。拿不准就不写。
2. **推断要标"推断"。** 动机大多是推断，要写清证据强弱，有反证就撤回。
3. **"没回、没看到后续"一律写"公开处没看到"。** 私信我们看不到。
4. **敏感信息**：健康、政治、宗教、子女、精确行踪、个人财务金额、第三方的签证身份。这些只用来理解他，不进给他的消息。最后一行写"跳过 N 处敏感信息（类别）"。
5. **会让人觉得被监视的内容**（作息、"你很少回谁"、评论统计）标"有点越界"，不进首屏。
6. **给本人的消息用英文**，自然、符合北美职场语气，下面附"中文意思"。
7. **凡是替他联系别人的事**，都按"Eazo 起草、本人确认、本人发出"。
8. **分析用中文大白话。** 每条短而具体：谁、哪天、说了什么、证据、意味着什么。不要写成长篇报告腔。
9. **篇幅**：正文（不算链接）约 2,000–3,500 汉字。宁少勿滥，只写证据最硬、最有用的。

## 输出格式（照这个写）

第一行是给总表用的一行数据：

`TABLE_ROW | 编号 | 姓名 主页链接 | 一句话画像（含身份） | 主要动机（一句话） | 最值得做的一件事 | 最该先核对的一条`

然后：

```
## <编号>｜<姓名> · <LinkedIn 主页链接>

**结论**：两三句话，说清三件事：他是什么样的人，为什么这么做，所以能为他做什么、不该做什么。

### 一、他是谁
只写事实：身份、阶段、影响力规模（写清出处）、时间约束（标明"不对他提"）。

### 二、他为什么这么做（动机，按主次）
每个动机写五样：
- 一句话说清是什么动机
- 支持的证据（附链接）
- 反面的证据
- 强弱：强 / 中 / 推断
- 用法：能不能对他提

### 三、他的做法怎么服务这些动机
分三块写：
- 发帖：节奏、时间、选题怎么变、什么内容效果好
- 评论别人：数量、对象、速度
- 回复自己帖下的留言：有什么规律

### 四、他回谁、不回谁，为什么
- 回复时间窗口：按留言到达时间分组的回复率，用表格写（剔除个人生活帖和发帖不到 48 小时的帖）
- 早到常客是什么性质
- 按他的动机，为什么这样做是合理的
- 真正可惜的是什么（如果有的话）

### 五、能为他做什么
写 3–5 条，每条写四样：
- 对上哪个动机
- 具体做法：谁、哪天、证据、Eazo 做什么
- 他会觉得有用吗
- 风险：可以 / 有点越界 / 越界

最后加一小节"撤回或不做的"：看起来像机会、但按他的动机不该做的事，每条写清为什么。

### 六、首屏 onboarding 消息
> 英文消息
中文意思：……
为什么这样写：对上哪个动机，只用了 onboarding 时能拿到的哪些数据。

### 七、后续可推消息（2–3 条）
每条写：
- 时机｜标题
- 英文消息原文
- 中文意思
- 任务：Eazo 起草什么、本人确认、本人发出

跳过 N 处敏感信息（类别）。
```

## 交回来之前自查

对照 `method.md` 末尾的自查清单逐项检查。特别是这三条：
- 每条"能做的事"都对上一个动机；
- "回谁不回谁"按到达时间看过；
- 所有链接都能在原始数据里找到。
