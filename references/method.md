# 方法：先懂人，再想能做什么

顺序：画像 → 动机 → 用动机解释行为 → 能做什么。前三步没做完，不写第四步。

## 1. 画像：他是谁（只写事实）

- **身份和阶段**：在哪家公司、做什么，是创始人、职员还是投资人，处在什么阶段（刚创业、在融资、在转型、在做个人品牌……）。
- **影响力规模**：有多少关注者，每帖大概多少赞和留言。
  - 关注者数要找出处，比如本人在帖子或评论里说过（`stats.txt` 的 A 节会把提到 followers / impressions 的句子找出来）。找不到就写"未知"，不要凭印象说"大 V"。
  - 例：用户以为样例 A 是大 V，她自己说过关注者不到 5 千，实际是成长期创作者。这个区别会改变后面所有判断。
- **时间约束**：全职工作、孩子、搬家、出差等。只用来理解他的时间安排，标明"不对他提"。

## 2. 动机：他为什么这么做

先列候选动机，再逐个用证据检验：
- 做个人品牌 / 涨影响力
- 为下一份工作铺路
- 本职工作需要（替公司发声、攒讲者身份）
- 变现（课程、咨询、newsletter、付费社群）
- 找客户 / 融资 / 招人
- 给自己留后路（副业、投资）
- 单纯分享、帮人

每个候选写清四样：
1. 支持的证据（带链接）；
2. 反面的证据；
3. 强弱：强 / 中 / 推断；
4. 用法：能不能对他提。

最后排出主次。

看动机最准的几个地方：
- **他换过什么方向、放弃过什么。** 把全部历史按月看（`stats.txt` 的 B 节）。例：样例 A 1–4 月做过一个理财号兼 newsletter，后来放弃，转做 AI PM 内容。这说明她底层想在工资之外给自己留后路。
- **什么火了他就追什么。** 对照 C 节（效果最好和最差的帖子）和 B 节的选题变化。追着数据走的，说明在经营影响力。
- **效果差还照发的内容。** 说明是职责或身份需要，不是为了流量。例：样例 A 替公司产品发的帖只有四五个赞，她照样发。
- **帖尾的固定签名和号召。** 比如 "Follow for more"、"Save this"、固定的自我介绍。
- **关键词线索**（D 节：变现、求职、创作者、副业）。要读原文判断他是在说自己，还是在教读者。

有反证就撤回。例："navigating a non-linear career" 看起来像在找工作，读原文发现是她写给读者的定位，撤回。

## 3. 用动机解释行为

### 发帖和评论
- **发帖节奏和时间**（E 节）：固定在黄金时段发，说明在经营。
- **评论别人**（F 节）：每天评论多少条、多快、评论谁。
  - 每天几十条、常常不到一分半钟一条、句式统一、专挑大号帖子：这是"借大号的观众涨粉"的打法，很可能有 AI 帮忙起草（推断）。
  - 评论对象表里看两列：本人的评论下面有没有人接话、对方来没来过本人的帖子。从这两列能看出他的评论时间花得值不值。

### 回谁不回谁（最容易误判，一定要做）
- **先看时间，再下结论。** H 节按留言在发帖后多久到来分组，看每组的回复率。
  - 汇总前人工剔除个人生活帖（这类帖子的回复规律不同）、发帖不到 48 小时的帖子、以及在 @ 别人而不是对本人说的留言。
  - 例：样例 A 发帖 24 小时内的 45 条留言，有回复的 37 条；24 小时以后的 12 条，只有 3 条。她不是挑人回，而是按时间回。
  - 再看本人当天的上网时段（F 节的时段分布、G 节的回复时间），晚到的留言往往是在他当天上网时间结束以后才来的。
- **分清常客的性质。** I 节列出"在多条帖下、1 小时内就到"的人。如果对方每次都一句复述式的话，本人又从没去过对方的帖子，多半是互评小组或自动评论工具。这种人不能当成"关系"，也不能当成"读者需求"。
- **识别真读者。** J 节列出晚到又没被回的留言，逐条读原文，看留言人是不是他的目标受众、说得有没有料。
- **判断合不合理。** 按他的动机，这样回复是合理的吗？
  - 时间有限、平台推荐只看前几个小时的互动、他的注意力已经在下一条帖子上，这些都会让"晚到不回"变得合理。
  - 合理的话，就不要把"没回"当成他的失误。

### 别的"没做"也一样处理
"答应过的事没兑现"、"别人推荐的人没回应"、"有人送东西没接"，都先问一句：
按他的身份和动机，他会在意吗？比如一个 CEO 收到大量陌生人的推销和推荐，不回是常态。

## 4. 能为他做什么

### 每条建议写四样
1. **对上哪个动机**（必须是第 2 步里排出来的）。
2. **具体做法**：谁、哪天、证据链接、Eazo 做什么。
3. **他会觉得有用吗**：设想你就是他，收到这条消息的第一反应是什么。
   - 好的建议通常是顺着他已有的习惯，帮他省时间或扩大结果。
   - 例：样例 A 自己已经会把留言区的争论写成下一条帖子，Eazo 只是把她看不到的晚到留言捞回来。
4. **风险**：会不会让他觉得被监视。分三档：可以 / 有点越界 / 越界。"有点越界"的条目不进首屏。

### 写一节"撤回或不做的"
把看起来像机会、但按他的动机不该做的事列出来，写清为什么。比如：
- "某某在等你回"（他本来就不需要回）；
- 替他向上级引荐一个只在评论区出现过一次的陌生人（他要承担社交成本，对他的目标又没帮助）；
- 提他放弃的副业、理财、孩子、搬家。

### 常见的好方向（按动机）
- **做影响力的**：
  - 把真读者的留言变成下一期内容，并在新帖里致谢、点名；
  - 告诉他评论时间花在哪里能换来对话；
  - 牵线同赛道、读者重合、有双向来往的同行一起做内容。
- **本职工作需要的**：把评论区里的客户、买方声音整理给他；找能来他活动的人。
- **创始人**：
  - 盯住有截止时间的事，比如融资窗口、活动报名；
  - 他的需求正好对上另一个熟人，两人又彼此不认识，可以牵线；
  - 他自己定过、但还没兑现的里程碑。
- **投资人**：被投公司和名单里的人有没有对得上的需求。

## 5. 首屏 onboarding 消息

- **对上主要动机，顺着他已有的习惯说。** 第一句要具体、能核对（日期、数字、他自己说过的话），不要泛泛地夸。
- **只用 onboarding 时能拿到的数据**：最近约 20 条帖子、约 20 条评论、最近几条帖子下的留言。
- **不要有"你欠谁回复"的味道。** 也不要让他知道我们掌握了他的作息、评论统计这类数据。

## 6. 自查清单（每个人写完都过一遍）

- [ ] 关注者数、影响力规模有出处，没有凭印象下判断
- [ ] 每个动机都有支持证据、反面证据和强弱标记
- [ ] "回谁不回谁"按到达时间看过，剔除了个人生活帖和进行中的帖
- [ ] 早到常客查过回访，没有被当成关系
- [ ] 每条"能做的事"都对上一个动机，并写了"他会觉得有用吗"
- [ ] 写了"撤回或不做的"
- [ ] 首屏消息只用了 onboarding 时能拿到的数据，没有越界
- [ ] 所有链接都来自原始数据（verify_links.py 结果为 0 个找不到）
- [ ] 敏感信息没进消息，最后写了跳过几处
